# Local-to-global feature scripts

This directory contains scripts for computing structure-level cumulant descriptors and
reconstruction errors between different cumulant orders and different uMLIPs.

* `run_cumulants.sh`. Computes cumulants (orders 1–8) for each model
* `run_errors_model.sh`. Runs reconstruction error for all pairs of cumulant orders for a single model
* `run_errors_umlip.sh`. Runs cross-model reconstruction errors across all models and and selected order

All outputs generated by the scripts are stored in the following folders:

* Cumulant descriptors: `./data/features/mad/cumulants/*`
* Reconstruction errors: `./results/mad/cumulants/*`
* Plots: `./figures/cumulants/*`
